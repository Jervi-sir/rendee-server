شروط استخدام تطبيق Rendee

تاريخ آخر تحديث: [05/10/2026]
تاريخ سريان الشروط: [05/10/2026]

باستخدامك لتطبيق Rendee أو بإنشائك حسابًا فيه، فإنك تقر بأنك قرأت هذه الشروط وفهمتها ووافقت عليها. إذا لم توافق عليها، لا تستخدم التطبيق.

1. التعريفات

Rendee أو التطبيق: المنصة الرقمية التي تتيح البحث عن مقدمي الخدمات الصحية وتنظيم طلبات المواعيد.

المستخدم أو المريض: كل شخص يستخدم حسابًا شخصيًا أو يحجز موعدًا أو يتصفح الخدمات.

مقدم الخدمة: الطبيب أو الصيدلي أو المخبر أو المركز الطبي أو المهني أو المؤسسة التي تقدم خدمة صحية أو ذات صلة.

الحساب المهني: حساب خاص بمقدم الخدمة لإدارة معلوماته وخدماته ومواعيده.

الموعد: طلب حجز أو موعد يتم عبر التطبيق بين المستخدم ومقدم الخدمة.

السجل الطبي: البيانات الصحية التي يختار المستخدم إدخالها في حسابه.

الملاحظات الخاصة: الملاحظات التي يضيفها مقدم الخدمة في مساحته المهنية الخاصة عن مستخدم أو موعد.

الاشتراك: الباقة المهنية المدفوعة التي تمنح مقدم الخدمة الوصول إلى الوظائف المهنية المتاحة وفق المدة والمزايا المتفق عليها.

2. طبيعة خدمة Rendee

Rendee منصة تقنية تساعد المستخدمين على:

- البحث عن الأطباء والمخابر والصيدليات والمراكز ومقدمي الخدمات.
- الاطلاع على المعلومات المنشورة من مقدم الخدمة.
- طلب وتنظيم المواعيد.
- متابعة حالة المواعيد.
- إدارة ملف شخصي وسجل طبي اختياري.
- تمكين مقدمي الخدمات من إدارة ملفاتهم المهنية وجداولهم وطلبات المواعيد.

Rendee لا يقدم طبًا أو تشخيصًا أو علاجًا أو وصفات طبية أو خدمات طوارئ. لا يحل التطبيق محل زيارة الطبيب أو الاستشارة الطبية المباشرة أو خدمات الإسعاف والطوارئ.

3. الحالات المستعجلة

لا تستخدم Rendee في الحالات المستعجلة أو التي قد تهدد الحياة.

في حالة الطوارئ، اتصل بخدمات الطوارئ أو توجه فورًا إلى أقرب مؤسسة صحية. لا تعتمد على حجز موعد عبر التطبيق للحصول على مساعدة طارئة.

4. الحسابات

4.1 الحساب الشخصي

يجوز للمستخدم إنشاء حساب شخصي أو تصفح بعض وظائف التطبيق كزائر عند إتاحة ذلك.

يلتزم المستخدم بما يلي:

- تقديم بيانات صحيحة ودقيقة ومحدثة.
- الحفاظ على سرية كلمة المرور.
- عدم مشاركة الحساب مع شخص آخر.
- إبلاغ Rendee فورًا عند الاشتباه في استخدام غير مصرح به للحساب.
- تحديث رقم الهاتف والبريد الإلكتروني عند تغيرهما.

    4.2 الحساب المهني

يجوز لمقدم الخدمة إنشاء حساب مهني بعد تقديم البيانات المطلوبة، وقد يخضع الحساب للمراجعة أو التحقق قبل تفعيله.

يلتزم مقدم الخدمة بما يلي:

- تقديم معلومات مهنية صحيحة وحديثة.
- تقديم رقم اعتماد أو ترخيص صحيح عند طلبه.
- المحافظة على سرية بيانات الدخول.
- تحديث الخدمات وأوقات العمل والعنوان ووسائل الاتصال.
- عدم إنشاء حساب مهني باسم شخص أو مؤسسة أخرى دون تفويض.
- عدم استخدام التطبيق لممارسة نشاط لا يملك ترخيصًا أو اعتمادًا له.

يجوز لـRendee تعليق أو رفض أو إنهاء الحساب المهني عند وجود معلومات خاطئة أو غير مكتملة أو مخالفة للقانون أو لهذه الشروط.

5. البحث والمعلومات المعروضة

يعرض Rendee معلومات مقدمي الخدمات التي يقدمها مقدم الخدمة أو يتم تحديثها داخل المنصة، مثل الاسم والتخصص والخدمات والعنوان وساعات العمل ووسائل الاتصال.

رغم أننا نسعى لتقديم معلومات دقيقة، لا نضمن أن تكون كل المعلومات محدثة أو خالية من الأخطاء في كل وقت. يجب على المستخدم التأكد من التفاصيل المهمة مباشرة مع مقدم الخدمة، خصوصًا قبل التوجه إليه.

6. المواعيد والحجوزات

6.1 إرسال طلب الموعد

عند الضغط على متابعة أو تأكيد الحجز، يرسل المستخدم طلب موعد إلى مقدم الخدمة المختار وفق التاريخ والوقت والخدمة المحددة.

قد يحتاج المستخدم إلى إدخال معلومات مثل الاسم ورقم الهاتف وتاريخ الميلاد ونوع الخدمة والملاحظات الاختيارية.

6.2 تأكيد الموعد

لا يصبح الموعد نهائيًا إلا عندما تظهر حالته كمؤكد داخل التطبيق أو يتلقى المستخدم إشعار تأكيد وفق آلية التطبيق.

قد يحق لمقدم الخدمة:

- تأكيد الموعد.
- اقتراح وقت أو تاريخ آخر.
- تعديل الموعد.
- إلغاء الموعد عند تعذر توفير الخدمة أو لأي سبب مهني أو تنظيمي مشروع.

    6.3 التزام المستخدم

يلتزم المستخدم بما يلي:

- الحضور في الوقت المحدد.
- الوصول قبل الموعد بمدة مناسبة إذا طلب مقدم الخدمة ذلك.
- حمل بطاقة الهوية أو الوثائق الطبية اللازمة إن طلبت العيادة أو المؤسسة.
- إخطار مقدم الخدمة أو اتباع آلية الإلغاء المتاحة عند عدم القدرة على الحضور.
- عدم إساءة استخدام نظام الحجز أو إنشاء حجوزات وهمية أو متكررة.

    6.4 مسؤولية مقدم الخدمة

يلتزم مقدم الخدمة بما يلي:

- التعامل مع طلبات المواعيد في وقت معقول.
- تحديث ساعات العمل والخدمات المتاحة.
- إخطار المستخدم عند التعديل أو الإلغاء.
- احترام خصوصية بيانات المستخدم.
- عدم استعمال بيانات المستخدم خارج ما يلزم لإدارة الموعد وتقديم الخدمة.

    6.5 عدم ضمان التوفر

Rendee لا يضمن توفر طبيب أو وقت أو خدمة معينة، ولا يتحمل مسؤولية تأخر مقدم الخدمة أو غيابه أو إلغائه أو تغيير جدول عمله. تكون المسؤولية المهنية عن تقديم الخدمة الصحية على عاتق مقدم الخدمة وحده.

7. السجل الطبي والبيانات الصحية

7.1 السجل الطبي للمستخدم

يمكن للمستخدم إنشاء سجل طبي اختياري يتضمن معلومات مثل فصيلة الدم والحساسيات والأمراض المزمنة والأدوية والمكملات والملاحظات الصحية.

المستخدم مسؤول عن صحة المعلومات التي يضيفها وعن تحديثها. لا يجوز استخدام السجل الطبي كبديل عن التشخيص أو الرعاية الطبية.

7.2 اطلاع مقدم الخدمة

عند الحجز لدى مقدم خدمة، يوافق المستخدم على إتاحة بيانات سجله الطبي لمقدم الخدمة المختار وفق سياسة الخصوصية، لمساعدته في إدارة الموعد وتقديم الخدمة الصحية.

7.3 ملاحظات مقدم الخدمة الخاصة

يجوز لمقدم الخدمة إضافة ملاحظات خاصة مرتبطة بالمستخدم أو بالموعد، وفق القوانين والالتزامات المهنية المنطبقة عليه.

تظل هذه الملاحظات في المساحة المهنية الخاصة بمقدم الخدمة أو المؤسسة التابعة له، ولا تظهر تلقائيًا لمقدم خدمة آخر عند حجز المستخدم لدى طبيب أو جهة أخرى.

7.4 التزامات مقدم الخدمة

يلتزم مقدم الخدمة بما يلي:

- استخدام البيانات الصحية فقط لغرض إدارة الموعد وتقديم الخدمة الصحية.
- الحفاظ على السرية المهنية والطبية.
- عدم نسخ بيانات المرضى أو تنزيلها أو مشاركتها أو بيعها أو استعمالها للتسويق.
- عدم الاطلاع على بيانات مريض إلا عند وجود علاقة موعد أو صلاحية مشروعة داخل التطبيق.
- عدم محاولة الوصول إلى ملاحظات مقدمي خدمات آخرين.
- تأمين جهازه وحسابه وعدم مشاركة كلمة المرور مع الغير.
- الالتزام بالقوانين والأخلاقيات المهنية الخاصة بمجاله.

8. اشتراكات مقدمي الخدمات

8.1 طبيعة الاشتراك

قد تتطلب بعض مزايا الحساب المهني في Rendee اشتراكًا مدفوعًا من مقدم الخدمة، مثل الطبيب أو الصيدلي أو المخبر أو المركز الطبي أو أي مؤسسة صحية تستخدم المنصة.

يتيح الاشتراك لمقدم الخدمة، بحسب الباقة المتفق عليها، إدارة ملفه المهني وخدماته وساعات عمله وطلبات المواعيد والإشعارات والوظائف المهنية المتاحة داخل التطبيق.

لا يفرض Rendee حاليًا أي رسوم على المستخدمين أو المرضى مقابل إنشاء حساب أو البحث عن مقدمي الخدمات أو طلب المواعيد عبر التطبيق.

8.2 مدة الاشتراك

يمكن لمقدم الخدمة اختيار إحدى مدد الاشتراك المتاحة داخل Rendee أو المتفق عليها مع فريق Rendee:

- اشتراك شهري.
- اشتراك لمدة ثلاثة أشهر.
- اشتراك لمدة ستة أشهر.

تبدأ مدة الاشتراك من تاريخ تفعيل الاشتراك أو من التاريخ المحدد في الفاتورة أو الوصل أو الاتفاق المبرم مع مقدم الخدمة.

8.3 الأسعار والباقات

تحدد أسعار الاشتراكات والباقة المشمولة والمزايا المتاحة قبل التفعيل أو التجديد.

يجوز لـRendee تعديل أسعار الاشتراكات أو محتوى الباقات مستقبلًا، على أن يتم إشعار مقدم الخدمة قبل تطبيق السعر الجديد على فترة اشتراك أو تجديد لاحقة.

لا يؤثر تعديل السعر على اشتراك مدفوع وساري المفعول قبل انتهاء مدته، إلا إذا كان التعديل مطلوبًا قانونًا أو تم الاتفاق عليه صراحة مع مقدم الخدمة.

8.4 طريقة الدفع

يتم دفع اشتراك مقدم الخدمة وفق طريقة الدفع التي تعتمدها Rendee وتبلغ بها مقدم الخدمة، مثل التحويل البنكي أو الدفع المباشر أو أي وسيلة أخرى يتم الاتفاق عليها.

لا يوفر التطبيق حاليًا خدمة دفع إلكتروني داخل التطبيق، ولا يجمع بيانات بطاقات الدفع أو كلمات المرور البنكية أو بيانات الحسابات البنكية داخل التطبيق.

8.5 التجديد اليدوي

التجديد في Rendee يدوي فقط.

لا يتم تجديد أي اشتراك تلقائيًا، ولا يتم خصم أي مبلغ تلقائيًا عند نهاية مدة الاشتراك.

يتحمل مقدم الخدمة مسؤولية طلب التجديد ودفع قيمة الاشتراك الجديد قبل أو عند انتهاء مدة اشتراكه، وفق طريقة التواصل أو الدفع التي تعتمدها Rendee.

يجوز لـRendee إرسال إشعار أو تذكير بقرب انتهاء الاشتراك، لكن عدم وصول التذكير لا يعفي مقدم الخدمة من مسؤولية متابعة تاريخ انتهاء اشتراكه.

8.6 انتهاء الاشتراك وعدم التجديد

عند انتهاء مدة الاشتراك وعدم تجديده، يجوز لـRendee تقييد أو إيقاف الوظائف المهنية المدفوعة، بما في ذلك استقبال طلبات المواعيد أو إظهار الحساب المهني للعامة أو إدارة بعض الميزات المهنية، بحسب الباقة والسياسات المعتمدة.

لا يؤدي انتهاء الاشتراك إلى حذف البيانات فورًا. تحتفظ Rendee بالبيانات وفق سياسة الخصوصية والقوانين المطبقة.

8.7 الإلغاء وعدم الاسترداد

يمكن لمقدم الخدمة طلب إلغاء الاشتراك أو عدم تجديده قبل نهاية مدته عبر وسائل التواصل المعتمدة من Rendee.

ما لم ينص القانون أو اتفاق مكتوب على خلاف ذلك، لا يتم استرداد المبالغ المدفوعة عن مدة اشتراك بدأت بالفعل، ولا يؤدي عدم استخدام مقدم الخدمة للتطبيق إلى استرجاع قيمة الاشتراك.

لا يمنع هذا البند تطبيق أي حق إلزامي لمقدم الخدمة يقرره القانون الجزائري.

8.8 الفواتير والإيصالات

عند توفرها، تصدر Rendee فاتورة أو وصل دفع أو إشعار اشتراك يوضح اسم مقدم الخدمة أو المؤسسة، مدة الاشتراك، الباقة، المبلغ، تاريخ الدفع، وتاريخ بداية ونهاية الاشتراك.

يلتزم مقدم الخدمة بتقديم بيانات صحيحة لإصدار الفاتورة أو الوصل.

8.9 عدم ضمان النتائج

الاشتراك في Rendee لا يمثل اعتمادًا طبيًا أو ترخيصًا لمقدم الخدمة، ولا يضمن عددًا محددًا من المرضى أو المواعيد أو الإيرادات أو الظهور داخل نتائج البحث.

يبقى مقدم الخدمة مسؤولًا عن التراخيص المهنية، وجودة خدماته، ومعلوماته المنشورة، وعلاقته المهنية والمالية المباشرة مع المرضى.

9. عدم وجود دفع إلكتروني للمرضى

لا يوفر Rendee حاليًا دفعًا إلكترونيًا داخل التطبيق للمستخدمين أو المرضى.

أي رسوم أو أتعاب طبية أو مخبرية أو صيدلانية أو مهنية، إن وجدت، يتم التعامل معها مباشرة بين المستخدم ومقدم الخدمة خارج تطبيق Rendee، ما لم يعلن لاحقًا عن خدمة دفع داخل التطبيق مع شروط خاصة بها.

10. الاستخدامات المحظورة

يحظر على أي مستخدم أو مقدم خدمة:

- تقديم معلومات مزيفة أو انتحال شخصية شخص أو مؤسسة أخرى.
- استخدام التطبيق لأغراض غير قانونية أو احتيالية.
- إنشاء حجوزات وهمية أو تعطيل خدمات التطبيق.
- محاولة اختراق التطبيق أو الوصول غير المصرح به إلى الحسابات أو البيانات.
- نسخ أو استخراج أو بيع أو نشر بيانات المستخدمين أو مقدمي الخدمات.
- استخدام التطبيق لإرسال رسائل مسيئة أو تهديدية أو تشهيرية أو مخالفة للآداب العامة.
- استخدام أسماء أو صور أو تراخيص مهنية دون حق.
- تحميل برمجيات ضارة أو محاولة تعطيل التطبيق أو خوادمه.
- استخدام بيانات المرضى أو مقدمي الخدمات في التسويق دون موافقة مناسبة.

11. الملكية الفكرية

جميع الحقوق المتعلقة بتطبيق Rendee، بما فيها الاسم التجاري والشعار والتصاميم والواجهات والبرمجيات وقواعد البيانات والنصوص والعلامات التجارية، مملوكة لـ [اسم الكيان القانوني] أو مرخصة لها.

لا يجوز نسخها أو تعديلها أو توزيعها أو استغلالها تجاريًا دون موافقة كتابية مسبقة.

يظل مقدم الخدمة مسؤولًا عن الحقوق المتعلقة بصوره وشعاره ونصوصه ومعلوماته المهنية التي ينشرها في حسابه.

12. الإيقاف أو التعليق أو الإنهاء

يجوز لـRendee، عند وجود سبب مشروع، تعليق أو تقييد أو إنهاء حساب المستخدم أو مقدم الخدمة، مثل:

- مخالفة هذه الشروط.
- تقديم بيانات غير صحيحة أو منتحلة.
- إساءة استخدام نظام المواعيد.
- انتهاك خصوصية المرضى أو المستخدمين.
- استخدام التطبيق لأغراض مخالفة للقانون.
- وجود خطر أمني أو تقني.
- عدم توفر اعتماد مهني صالح عند الحاجة إليه.
- عدم تجديد اشتراك الحساب المهني بعد انتهاء مدته.

سنحاول إشعار المستخدم أو مقدم الخدمة عند الإمكان، إلا إذا كان الإشعار قد يسبب ضررًا أو خطرًا أمنيًا أو مخالفة قانونية.

13. حدود المسؤولية

ضمن الحدود التي يسمح بها القانون:

- Rendee منصة تقنية وليست مقدم خدمة طبية.
- لا تتحمل Rendee مسؤولية التشخيص أو العلاج أو الوصفات أو القرارات أو الأخطاء المهنية الصادرة عن مقدم الخدمة.
- لا تتحمل Rendee مسؤولية جودة الخدمة الطبية أو توفرها أو نتائجها.
- لا تتحمل Rendee مسؤولية المعلومات التي ينشرها مقدم الخدمة إذا كانت غير دقيقة، مع احتفاظها بحق مراجعة أو إزالة المحتوى المخالف.
