# Nginx Setup Instructions for Rendee

This guide sets up Nginx for **`rendee.app`**, **`www.rendee.app`**, and **`for-mobile.rendee.app`** proxying to the local service on port `18040`.

---

## 1. Nginx Configuration File

Save the configuration below to `/etc/nginx/sites-available/rendee.app` (or copy from `z-docs/rendee.app.conf`):

```nginx
# HTTPS Server Block (All 3 domains)
server {
    listen 443 ssl http2;
    server_name rendee.app www.rendee.app for-mobile.rendee.app;

    # Allow Let's Encrypt SSL renewals
    location ^~ /.well-known/acme-challenge/ {
        allow all;
    }
    location ~* ^/.well-known/ {
        return 403;
    }

    location / {
        proxy_pass http://localhost:18040;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_buffer_size 128k;
        proxy_buffers 4 256k;
        proxy_busy_buffers_size 256k;
    }

    # SSL Certificates generated by Certbot
    ssl_certificate /etc/letsencrypt/live/rendee.app/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/rendee.app/privkey.pem;
    include /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;
}

# HTTP to HTTPS Redirect
server {
    listen 80;
    server_name rendee.app www.rendee.app for-mobile.rendee.app;

    location ^~ /.well-known/acme-challenge/ {
        allow all;
    }

    location / {
        return 301 https://$host$request_uri;
    }
}
```

---

## 2. Step-by-Step Commands to Apply

### Step 1: Copy config to `sites-available`
```bash
sudo cp /home/jervi/projects/rendee-server/z-docs/rendee.app.conf /etc/nginx/sites-available/rendee.app
```

### Step 2: Enable the site
```bash
sudo ln -sf /etc/nginx/sites-available/rendee.app /etc/nginx/sites-enabled/
```

### Step 3: Test Nginx configuration
```bash
sudo nginx -t
```
*You should see:* `nginx: configuration file /etc/nginx/nginx.conf test is successful`

### Step 4: Reload Nginx
```bash
sudo systemctl reload nginx
```

## 3. Verify SSL & Renewal (Only rendee.app)

To test dry-run renewal **only** for this certificate (without checking all other sites on your server):
```bash
sudo certbot renew --cert-name rendee.app --dry-run
```

To view current status/expiry of only this certificate:
```bash
sudo certbot certificates --cert-name rendee.app
```
